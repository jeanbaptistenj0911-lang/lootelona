#Lootelona

Lootelona is a classifieds marketplace where people can post items for sale,
browse and search nearby listings, and contact sellers directly.

## Tech Stack
Django · SQLite · Tailwind CSS

## Features (MVP)
- Register / login / logout
- Post an ad with photos
- Search and filter by category, price and city
- Ad detail page with seller contact
- My Ads (edit, delete, mark as sold)

## Status
In development
